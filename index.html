About Maia Platform

Independent software, built to be understood.

Maia Platform is an open-source ecosystem created by Roberto Monteiro. It connects long-running work in software engineering, computational modeling, artificial intelligence, education and applied research.

The platform favors practical tools, local ownership of data and infrastructure, browser-first applications and reusable foundations for future products.

Deploy with Maia Edge

Cloud entry. Local power.

Use a lightweight VPS as a secure public gateway while applications, databases and AI workloads run on your own hardware.

$ git clone https://github.com/souzamonteiro/maia-edge
$ cd maia-edge
$ make validate

Follow the platform as it evolves.

Source code, experiments and documentation are published openly on GitHub.

Meet the Founder

Maia Platform is the result of more than two decades of work by Prof. Roberto Luiz Souza Monteiro, combining software engineering, artificial intelligence, computational modeling, formal languages and applied research into a unified open-source ecosystem.

His work bridges academia and industry through research, engineering, education and practical software designed to solve real-world problems.
